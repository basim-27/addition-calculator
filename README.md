# Simple Prompt Addition Calculator

A lightweight JavaScript application that takes two numbers as input via browser prompts and displays their total sum in an alert box.

## Features

* **Browser Prompts:** Simple input prompts to take two integer numbers from the user.
* **Instant Calculation:** Computes the addition using JavaScript's `parseInt()` function.
* **Alert Output:** Displays the calculated sum directly in a browser alert window.

## Project Structure

* `index.html` - Basic HTML layout linking the JavaScript file.
* `script.js` - Contains the input prompt logic and addition calculation.
